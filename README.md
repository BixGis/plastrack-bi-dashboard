# PlasTrack BI Dashboard

Proyecto académico PlasTrack – Unidad 1.

Este repositorio contiene un dashboard estático de Business Intelligence para monitorear pasadas satelitales simuladas sobre el archipiélago de Galápagos, desarrollado con HTML5, CSS3, JavaScript, Leaflet.js y Chart.js. Todos los datos son simulados y se encuentran en `data/data_copernicus_sample.json`.
